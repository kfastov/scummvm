# 0005 — Баг движка: палитра приёмника в конвертере видеокадров

**Дата:** 2026-08-11
**Статус:** ✅ кандидат в апстрим
**Тип:** ошибка ScummVM

`engines/director/castmember/digitalvideo.cpp` передавал `_ditheringPalette` в
параметр **исходной** палитры `Surface::convertTo`, хотя это копия текущей
палитры игры, то есть приёмник. В 8-битном режиме палитра приёмника оставалась
пустой, и `convertTo` падал с «Unsupported dithering target format or missing
palette» на любом полноцветном кадре видео.

Правка выбирает источник и приёмник по глубине кадра и экрана. Чинит не только
эту игру, а любую с видео в 8-битном режиме.
