# 0018 — Семь ведьм: игра проходится

**Дата:** 2026-08-12
**Статус:** ✅
**Тип:** состояние работ

Полный проход воспроизводится скриптом `tools/witches.py`:

    ./tools/witches.py main    — до города (2 мин 40 с)
    ./tools/witches.py tour    — обход всех семи локаций со снимками

**Что работает:** проверка компакт-диска → выбор языка → выбор сохранения
(клик по ботинку) → заставка города → город → любая из семи локаций
(`Turm`, `Kneipe`, `Markt`, `Ecke`, `Salon`, `Laden`, `Spielpl`) → возврат
в город. Внутри локаций отзываются предметы (в «Салоне» 37 интерактивных
спрайтов), нижняя панель с подарками на месте, озвучка находится и играет.

**Тонкость управления, которая сбивает автоматику:** в городе кликать надо не
по картинке дома, а по спрайту-подсветке, который скрипт кадра подводит под
курсор при наведении. Поэтому перед кликом обязательно движение мыши и пауза
на кадр. И точка выбирается не по центру прямоугольника: попадание считается по
маске картинки, а в середине `Ecke` она прозрачна.
