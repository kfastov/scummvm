# Опыты с распаковкой картинок книги ToolBook

Три маленькие программы на C — потому что перебор начала данных на Python
не укладывается ни в какое время (десятки тысяч проб по 50 тысяч шагов).

    cc -O3 -o dump dump.c && ./dump <книга> <dib> <данные> <ш> <в> <comp> out.bmp
    cc -O3 -o find2 find2.c && ./find2 <книга> <dib> <raw> <comp> [окно]
    cc -O3 -o survey survey.c && ./survey <книга>

* `dump` — распаковать и записать BMP. **Смотреть картинку глазами обязательно**:
  совпадение размеров ничего не доказывает (ledger/0029, 0030).
* `find2` — искать начало данных: сначала дешёвый фильтр по соотношению
  вход/выход на первых 1500 байтах, потом полная проба.
* `survey` — сколько полноэкранных фонов разворачивается прямо из-за палитры.

Переменные окружения: `RUNADD` (длина серии `c + RUNADD`, по умолчанию 3),
`TRUNC`/`TRUNCLIT` (обрезка на конце строки; правильный ответ — 0, см. 0030).
