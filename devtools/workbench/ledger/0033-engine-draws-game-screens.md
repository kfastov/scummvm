# 0033 — Движок рисует настоящие экраны игры

**Дата:** 2026-08-13
**Статус:** ✅ веха, ⚠️ картинка полосами
**Тип:** реализация

Раскладка потоков из 0032 перенесена в движок. Вместо слепого перебора со
сверкой размеров (который находил чужие данные, 0029) теперь так:

1. у каждой картинки считается **база сегмента**: блок с DIB занимает
   `4 + 40 + палитра` байт, поле «конец» в его заголовке даёт смещение конца от
   базы, отсюда база;
2. картинки группируются по базе; для группы цепочкой блоков находится **конец
   сегмента**;
3. от конца сегмента потоки раскладываются **жадно**: одна распаковка на
   позицию, по дороге проверяются все ещё не размещённые картинки группы, и
   найденный поток задаёт начало поиска следующего.

Работает: в логе видно `поток @0x175ac0 -> картинка @0x1757a9 640x480
comp=232673 (вход 232696)` и такие же строки для других страниц.

**На экране появились настоящие экраны «Башни знаний»** — заставка с надписью
«БАШНЯ ЗНАНИЙ» на фоне каменных арок и уровень-лабиринт с кристаллом. Раньше
страницы были чёрными с надписью «данные не найдены».

## Чего не хватает

Картинка идёт **горизонтальными полосами**: каждая полоса высотой в 20–60 строк
сдвинута вбок на своё расстояние. Суммарные размеры при этом сходятся почти
точно (вход 232 696 против 232 673 по заголовку, +23 байта на всю картинку).

Замер сдвигов построчной корреляцией по всей ширине даёт восемь мест с крупным
сдвигом; входные смещения на границах — 161 627, 181 213, 191 529, 199 076,
202 146, 211 303, 214 178. Разности между ними (19 586, 10 316, 7 547, 3 070,
9 157, 2 875) **не образуют никакой правильной сетки** — значит это не куски по
64 КБ, как предполагалось в 0031, и не построчные заголовки.

Проверено и отпало: сдвиги не кратны ширине строки; общий расход входа не
оставляет места для крупных вставок.
