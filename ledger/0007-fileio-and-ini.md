# 0007 — Баги движка в FileIO и подставной hexen.ini

**Дата:** 2026-08-12
**Статус:** ✅ два кандидата в апстрим + обход
**Тип:** ошибка ScummVM / обход под игру

**Симптом.** `ERROR: Builtin 'getAt' did not return value!` сразу после выбора
языка. Трассировка дала цепочку `readFile(...)` → `member(...)` → `value("")` →
`getAt(0, 1)`: игра читала файл настроек, получала пустую строку, `value("")`
возвращал ноль.

Механизм настроек (`GLOBAL.CST-MovieScript-13`, обработчик `prefs`): системный
каталог Windows → `hexen.ini` → путь из второй строки после «=» → `hexen.txt` с
состоянием игроков. Отсутствие файла состояния игра переживает (подставляет шесть
строк нулей), отсутствие `hexen.ini` — нет.

Понадобились три правки:

1. **`FileIO::m_openFile`, режим 0** был отображён на `append`, хотя в Xtra это
   чтение-запись. Открытие отсутствующего файла завершалось успехом, чтение
   давало пустоту, и собственная ветка игры «файла нет» не срабатывала никогда.
   Теперь режим 0 — чтение. *(кандидат в апстрим)*
2. **`FileIO::m_getOSDirectory`** был заглушкой с пустой строкой, пути собирались
   как `\hexen.ini` вместо `C:\WINDOWS\hexen.ini`. *(кандидат в апстрим)*
3. **Подставной `WINDOWS/hexen.ini`** через штатный механизм `cachedFiles` — как
   уже сделано для `PATH.INI` в играх TKKG и `INSTALL.INF` в PAWS. *(обход)*

После этого игра доходит до экрана выбора сохранения.
