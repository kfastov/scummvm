# 0004 — Проверка компакт-диска: обход через букву E

**Дата:** 2026-08-11
**Статус:** ✅
**Тип:** обход под игру

Стартовый скрипт перебирает буквы дисков C..Z, ищет каталог `Datas\turm\` и
сравнивает первый файл в нём со строкой `freu01.dir`, затем проверяет носитель
на запись: если файл удалось создать, значит это винчестер, и путь сбрасывается.

Значения полей вытащены из `Prince.exe` (чанки `TXTS`): `CDName="Tivola"`,
`Zielpfad="Datas"`, `suchpfad="Datas:turm"`, `suchdatei="freu01"`,
`startdatei="titel"`, `schreibdatei="hexen.tmp"`.

**Почему не проходило:** цикл останавливается на первой подошедшей букве, а у нас
подходит любая — игра выбирала `C:`, куда FileIO пускает писать. При этом в
движке уже есть соглашение (`xlibs/f/fileio.cpp`): диск `E:\` изображается
доступным только для чтения, «чтобы помочь с проверками CD во многих играх».

**Обход** (`quirkSevenWitches`, поле `_cdDriveLetter`):
`getNthFileNameInFolder` отвечает пустой строкой для всех букв, кроме `E`. Игра
доходит до `E:`, тест на запись честно проваливается, проверка пройдена.
Новых механизмов не заводили — привели игру к уже существующему в движке.
