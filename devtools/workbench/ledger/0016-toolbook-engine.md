# 0016 — Башня знаний: движок toolbook в ScummVM

**Дата:** 2026-08-12
**Статус:** ⚠️ движок есть и работает, игра не воспроизводится
**Тип:** реализация

Заведён движок `engines/toolbook` в своей сборке ScummVM.

**Что работает:**

- детект игры (`KNTOWER.EXE`, md5 `bfddff37…`, 38 831 653 байта) — цель
  `toolbook:knowledgetower`;
- разбор книги прямо из `.EXE` (книга лежит куском со смещения `0x29e0`):
  289 записей, 25 сегментов, 2483 картинки, 51 страница, 23 класса объектов;
- перекодировка текста CP1251 → UTF-8;
- разворачивание тех картинок, которые лежат несжатыми (69 из 2483), и их
  просмотр по клавише `i`;
- листание страниц: для страницы с несжатым фоном рисуется фон, иначе —
  что про страницу известно (имя, обработчики, текст).

**Чего нет:** интерпретатора OpenScript. Без него нет ни кнопок, ни переходов
по логике игры, ни мини-игр, ни звука через MCI. Листание сделано клавишами и
щелчком по половинам экрана — это не игровая навигация, а обход книги.

**Важное решение:** движок **не рисует** картинки, сжатие которых не разобрано.
Раньше он показывал их как есть и выдавал цветной шум, похожий на «почти
работает». Правило из 0012 — не принимать отсутствие ошибки за успех —
относится и к картинке: пусть лучше честно пишет «фон сжат, не разобран».

**Что делать дальше, по порядку:**

1. Разобрать сжатие картинок (поток за палитрой, начинается с
   `01 00 00 00 01 00 00 00 00 00`). Без него не будет ни одной сцены.
2. Разобрать байт-код OpenScript: опкоды, кадр стека, вызовы обработчиков.
   Опора — совпадающие побайтово копии одного обработчика в разных объектах и
   привязка строковых операндов к именам.
3. Собрать объекты страницы (кнопки и поля с прямоугольниками) — тогда
   появятся настоящие точки нажатия вместо половин экрана.
