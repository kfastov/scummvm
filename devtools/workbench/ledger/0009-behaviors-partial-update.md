# 0009 — Баг движка: поведения теряются при частичном обновлении канала

**Дата:** 2026-08-12
**Статус:** ⚠️ правка верна, но проблему клика не решает
**Тип:** ошибка ScummVM

**Замеры по шагам** (каждый опроверг предыдущую догадку):

1. У спрайта туфли `spriteListIdx` есть (654), список поведений пуст.
2. Блок деталей в файле **не пуст**: `[654]=44` (описание), `[655]=8`
   (поведения), `[656]=0` (имя).
3. Поведения **исправно загружаются** — по одному на каждую туфлю.
4. Теряются при передаче в канал.

**Причина.** В `Channel::setClean` есть ветка частичного обновления, где из новых
данных кадра копируется только `_scriptId`. Список поведений остаётся старым,
пустым. Поведения — такое же прикрепление скрипта, как идентификатор, и без них
`respondsToMouse` возвращает ложь для D6: спрайт рисуется, но перестаёт замечать
клики.

**Правка** дописывает копирование поведений в эту ветку. Проверено: канал 9 под
курсором сменил «тест 1, отвечает 0» на «тест 1, отвечает 1».

**Но клик всё равно не проходит** — правка необходима, но недостаточна. См. 0010.
