# 0001 — Стенд Windows 98 в QEMU, управляемый скриптами

**Дата:** 2026-08-11
**Статус:** ✅
**Тип:** инфраструктура

`3-vm.sh` — QEMU + Windows 98 SE (TCG, Pentium III, Cirrus, SB16, PCnet).
`tools/qmon.py` — управление гостем через монитор QEMU: клавиши, мышь, снимки
экрана. Установка ОС проведена скриптами, без рук.

Что стоило времени и записано, чтобы не повторять:

- **Сброс внутри процесса QEMU убивает Windows 98.** Перезагрузка из меню Пуск,
  `system_reset` и `loadvm` одинаково вешают гостя в реальном режиме (EIP замирает
  около `0x9dfb`). Перезапуск — только новый процесс.
- **USB в госте не установлен**, поэтому `usb-tablet` для него не существует и
  абсолютные координаты не доходят. Мышь — только PS/2.
- **HMP-команды мыши монитор принимает молча**, но до гостя они не доходят.
  Работает лишь QMP `input-send-event`.
- **Акселерацию указателя надо гасить** (`guest-tools/NOACCEL.REG`,
  `MouseSpeed=0`), иначе относительные сдвиги домножаются и курсор улетает в угол.
- Передача файлов в гостя — через ISO (`hdiutil makehybrid`), диск меняется на
  ходу командой `change ide1-cd0`. ISO нельзя держать примонтированным в macOS
  одновременно: QEMU не получит блокировку.
