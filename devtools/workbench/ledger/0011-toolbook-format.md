# 0011 — Башня знаний: формат книги ToolBook размечен

**Дата:** 2026-08-12
**Статус:** ✅ разметка и инструмент; байт-код не разобран
**Тип:** исследование формата

Книга извлечена из `KNTOWER.EXE` (offset `0x29e0`) в `games/bashnya/kntower.tbk`:
38 820 933 байта, сигнатура `\x03JBO`, **617 именованных сегментов** против
двенадцати в ресурсной `RESOURCE.TBK`. Базовая дюжина (`*ClassTbl*`, `*PTABLE*`,
`*OBJTABLE*`, `*IDTABLE*`, `*NAMETAB*`, `*RHOTWORD*`, `*TbxBase*` …) лежит
с `0x134995`.

**Инструмент `tools/tbk.py`:** команды `extract`, `segments`, `records`,
`bitmaps`, `strings`, `disasm`. На игровой книге — 227 записей, 69 битмапов.

**Три вывода, сокращающих будущий интерпретатор:**

1. **Графика лежит готовыми Windows-битмапами.** Сразу за маркером записи идёт
   сигнатура `BM`; извлечённые файлы открываются штатно (первый — 37×35, 8 бит).
   Свой декодер изображений не нужен.
2. **Мультимедиа идёт через MCI.** В строках лежат готовые команды Media Control
   Interface — `wav alias mySound buffer 8 wait`, `play mySound`,
   `stop mapMidi wait`, — и экранные переходы `vertical split out speed 2000`,
   `drip speed 2600`. Эмулировать надо знакомый строковый интерфейс.
3. **Скрипты скомпилированы.** Текстовых форм OpenScript в книге нет; имена
   вкраплены в поток команд, а не собраны в отдельную таблицу.

**Маркер границы записи:** `2a 00 01 02 01 00`, 227 вхождений, медианное
расстояние ≈ 2964 байта.

**Первая статистика по байт-коду** (4 КБ у `0x67518`): операнды почти всегда
отрицательны и кратны четырём — `-4` (82 раза), `-8` (31), `-12` (28), — что
характерно для слотов кадра стека с шагом 4. Перед операндом чаще всего `0x02`
(101 раз), затем `0x0d` (44) и `0x0f` (14).

**Что уже видно в идентификаторах:** обработчики `mouseEnter`, `mouseLeave`,
`ButtonDown`, `timerNotify`, `firstIdle`; логика `InitGame`, `ResetKristall`,
`openPopka`, `showKristall`, `resetHelp`; объекты сцен латиницей по-русски —
`stol`, `chasi`, `palma`, `solnt`, `poesd`, `samol`.

**Опровергнутая по дороге гипотеза:** последовательность `e0 09 91 5a` была
принята за разделитель записей по выборке из маленького ресурсного файла. В
основной книге таких вхождений всего 52 против 317 вхождений `buttonClick` —
вывод был построен на нерепрезентативной выборке.
