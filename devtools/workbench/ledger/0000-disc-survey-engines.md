# 0000 — Разведка дисков: Director 6 и 16-битный ToolBook

**Дата:** 2026-08-11
**Статус:** ✅
**Тип:** разведка

Оба образа с трекеров оказались raw-дампами по 2352 байта на сектор, macOS их не
монтирует. «Башня знаний» — Mode 2 Form 1, «Семь ведьм» — Mode 1. Конвертер —
`tools/raw2iso.py`, результат в `downloaded/iso/`.

| | Семь ведьм | Башня знаний |
|---|---|---|
| Год, издатель | 2001, Tivola / Бука | 1996, New Media Generation |
| Движок | Macromedia **Director 6** | Asymetrix **Multimedia ToolBook 4.0** |
| Скрипты | Lingo (`Datas/*.DIR`, `GLOBAL.CST`) | OpenScript (`RESOURCE.TBK`, книга внутри `KNTOWER.EXE` с `0x29e0`) |
| Исполняемые | PE, 32-битный проектор `Prince.exe` | **NE, 16-битные** |

Следствие: у ведьм есть готовый путь — движок `director` в ScummVM. У «Башни»
открытых реализаций нет, 16-битный код не запустит ни Wine на ARM, ни Windows 11
ARM — нужен либо эмулятор целого ПК, либо свой интерпретатор.
